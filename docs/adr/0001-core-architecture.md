# ADR-0001 — PostgreSQL как источник истины и явные конфликты офлайн

Статус: принято для первого инкремента.

При конкурирующих действиях Last-Write-Wins может безвозвратно потерять работу инженера или изменение диспетчера. Поэтому клиент передаёт UUID и версию заявки. Сервер применяет действие только при совпадении версии и допустимом статусе, а повтор UUID отвечает duplicate. Конфликт возвращается явно, IndexedDB не удаляет черновик.

Политика SLA сохраняется снимком внутри Ticket в момент создания. Дедлайны считаются по рабочему календарю в зоне объекта. История нарушений ведётся в событиях, не пересчитывается при изменении политики.

Медиа хранятся приватно в MinIO. API проводит повторную авторизацию каждого файла. Никаких публичных presigned URL в первом релизе.

Worker сканирует PostgreSQL по расписанию, а уникальный event_key обеспечивает отсутствие повторных уведомлений после рестарта. Mock inbox сохраняет автономность, но не является реальной доставкой SMS/email.

Ограничения: неатомарная запись файла и БД, необходимость нагрузочного тестирования PostgreSQL, отдельного мониторинга очереди и очистки сирот.
