# Импорт объектов и договоров из CSV

Командный импорт предусмотрен для начальной настройки. Импорт в UI администратора ещё не реализован.

Схемы и примеры находятся в examples/sites.csv, examples/assets.csv и examples/contracts.csv. Порядок запуска: sites → assets → contracts.

Команды после docker compose up -d --build:

- docker compose exec -T api python -m app.import_csv sites /srv/fieldpulse/examples/sites.csv
- docker compose exec -T api python -m app.import_csv assets /srv/fieldpulse/examples/assets.csv
- docker compose exec -T api python -m app.import_csv contracts /srv/fieldpulse/examples/contracts.csv

Добавьте --dry-run для проверки без сохранения. При ошибке строки изменения целого файла откатываются.

При повторном импорте объекты/оборудование с тем же сочетанием имени/города пропускаются. Для договоров совпадающая политика тоже не меняется; иная политика создаётся отдельно с обновлением привязки, исторические снимки в заявках не переписываются.

Для рабочих дней используются номера 0=понедельник … 6=воскресенье. Несколько значений разделяются точкой с запятой и должны быть внутри одной CSV-ячейки. Праздники перечисляются в формате YYYY-MM-DD. Часовой пояс указывается IANA-именем.

Ограничения: внешний ID объекта в текущем шаблоне заменён парой (site_name, city). При одинаковых именах в одном городе импорт оборудования и договоров возвращает ошибку неоднозначности вместо выбора произвольного объекта.
