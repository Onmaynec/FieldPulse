# FieldPulse v0.3.0 — Синтетический профиль 200/1000

Источник: CI run [43551444016](https://github.com/Onmaynec/FieldPulse/actions/runs/43551444016), GitHub Actions Ubuntu 24.04, 14 ноября 2026 года. Полный CI того запуска позже остановился из-за неверного пути импорта теста worker; **сама нагрузочная фаза завершилась без ошибок**.

## Конфигурация теста

- Синтетический профиль: 200 созданных заявок, 1000 загруженных фотографий (5 на каждую заявку).
- Параллельных работников: 8; CPU count: 4; Linux 7.0.0-1014-aws x86_64, Python 3.12.16.
- Одно демонстрационное здание; все фотографии — идентичные синтетические JPEG по 1829 байт, что **не соответствует реальным фотографиям размером до 10 МиБ**.
- Запуск поверх воспроизводимого seed: 120 объектов, 600 единиц оборудования, 45 инженеров, 2000 заявок.
- Измерение — короткий интенсивный прогон, а не распределение событий по 24 часам.

## Вывод и ограничения

Для синтетических коротких запросов профиль завершён. Однако не проверены реалистичные медиа до 10 МиБ, суточная продолжительность, деградация диска, сетевые отказы, мониторинг RAM/CPU в процессе и повторяемость на нескольких запусках. **AT-11 пока нельзя считать полностью пройденным.**
