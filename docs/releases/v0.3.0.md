# FieldPulse v0.3.0 — Stabilization & Acceptance

Версия посвящена надёжности данных и воспроизводимым проверкам. Масштабный визуальный редизайн сознательно перенесён на v0.4.0.

## Изменения

1. **SLA:** отчёты по объектам, сверка заявок с Event/Pause, мониторинг mock-очереди, корректные повторные предупреждения при изменении дедлайна.
2. **Офлайн:** IndexedDB подтверждает фиксацию транзакции, пакеты до 30 действий, сохранение конфликтов. Добавлен браузерный сценарий с двумя фото и отключением сети.
3. **Восстановление:** архив PostgreSQL и S3 с SHA-256 манифестом и отдельной проверкой. Восстановление допускается только в пустую инсталляцию.
4. **Медиа:** поиск сирот с минимум 24 часами отсрочки, без автоматического удаления.
5. **Нагрузка:** конфигурируемый генератор с JSON p50/p95, числом ошибок, CPU count, числом одновременных работников. В CI малый тест; целевая производительность ещё не доказана.
6. **Календарь:** несколько рабочих интервалов в сутки без изменения дизайн-системы.

## Ограничения

Не проводились натурный 48-часовой офлайн-тест, целевые замеры 200 заявок/1000 фото за сутки на документированном оборудовании, полностью изолированный disaster recovery drill и внешний аудит безопасности. Это не финальная приёмка PV-FSM-02.

## План v0.4.0 — Visual Overhaul

Следующее обновление будет максимально сосредоточено на визуальной части. Планируются полный редизайн страниц входа, дашбордов, заявок, карточек, аналитики, клиентского кабинета, инженерной PWA, актов и административной панели; новая дизайн-система, типографика, иконки, сетки, состояния, светлая/тёмная палитры и анимации.

В дополнение: адаптивность 320–2560 px, доступность с клавиатуры, reduced-motion, контраст, проверка визуальных регрессий. Серверные сценарии и модели данных должны остаться совместимы.

**Ни один из перечисленных визуальных пунктов не выдаётся за реализованный в v0.3.0.**
